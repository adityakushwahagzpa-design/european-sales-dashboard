# European Sales Dashboard | Excel

An interactive Excel dashboard on EU Superstore orders, **2015–2018: 10,000 order lines, 5,122 orders, 15 countries**. Pick a country and year and every KPI, table and chart updates through SUMIFS formulas.

## Build
- Data cleaning: duplicate checks, de-duplicated returns, and a fix for 473 Order IDs reused across customers
- Calculated columns: year, month, ship days, discount band, returned flag, profit margin
- KPI cards, monthly trend, category, segment, country and discount-band views
- Named ranges for readable formulas

## Key findings
- Total sales **€2.94 million**, profit **€372.8K**, margin **12.7%**; return rate 6.1%
- Orders with no discount earn a **25.2%** margin
- Discounts of 21–40% run at a **–24.0%** margin and discounts over 40% at **–59.6%**, losing €164.7K together
- Furniture has the lowest category margin (8.8%)
